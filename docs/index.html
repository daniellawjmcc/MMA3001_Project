MMA3001 Engineering Project

Deep Learning for Pork Packaging Defect Detection

Comparative evaluation of YOLOv8n, RetinaNet ResNet50-FPN V2 and Faster R-CNN ResNet50-FPN V2 for automated pork rasher packaging quality inspection.

Project Overview

This project evaluates three deep learning object detection architectures for identifying four defect categories: loose-meat, packaging-error, twisted-meat and unsealed.

Models are compared using COCO-style average precision, confidence-threshold sensitivity, per-class performance, generalisation and computational requirements.

3 Detection architectures
4 Final defect categories
120 Validation images
80 Held-out test images

Main Experimental Results

The following results use a common COCO-style evaluation protocol.

Model Validation mAP@50:95 Test mAP@50:95
YOLOv8n 0.3278 0.2698
RetinaNet 0.2465 0.1494
Faster R-CNN 0.3222 0.1482

YOLOv8n achieved the highest held-out test mAP@50:95 and the smallest validation-to-test performance decrease among the evaluated models.

Code Documentation

The shared Python package is located in src/mma3001/. API documentation is automatically generated using pdoc and the Google-style docstrings in the source files.

The package includes configuration management, dataset loading, data preparation, checkpoint loading, evaluation metrics and plotting utilities.

To regenerate the documentation, execute python build_docs.py from the repository root.

Reproducibility

Training reproduction scripts are stored in training/. They support the preliminary five-class experiments and the final four-class models.

Tests are stored in tests/ and may be executed with python -m pytest -q.

Original checkpoints and prepared datasets are maintained separately from the Git repository. Reproduction scripts use separate output directories to protect these original artifacts.
